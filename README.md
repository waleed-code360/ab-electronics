# AB Electronics — Showroom Hero + Mobile V4

This is the complete website package.

## What changed

### Hero slider
The homepage hero uses **only the real AB Electronics showroom/store photos supplied by the client**:

1. Storefront
2. Haier AC display
3. Refrigerator display
4. Washing machine display
5. LED TV display
6. Microwave / kitchen display

No product cutout image is used in the hero.

Product cards and product-detail pages continue to use exact Haier product imagery generated by the Haier Pakistan catalog sync workflow.

### Mobile
The site has been specifically polished for iPhone + Android:

- `viewport-fit=cover` for iOS safe areas
- mobile-friendly 16px search inputs (avoids Safari auto-zoom)
- sticky mobile navigation
- touch-friendly hamburger menu
- hero photo appears before hero text on mobile
- swipe left/right on the hero slider
- compact hero typography and buttons
- horizontal swipeable category filters on the catalog
- one clean product card per row on phones
- compact product detail page
- smaller/safer entrance animations on mobile
- reduced-motion support remains enabled
- no horizontal overflow

## Replace existing project

Keep the hidden `.git` folder in your local repository and replace the other visible files/folders with the contents of this package.

Then:

```powershell
git add -A
git commit -m "Use showroom-only hero and improve mobile experience"
git push
```

Keep GitHub Pages set to:

**Settings → Pages → Source: GitHub Actions**

The existing workflow still rebuilds the live Haier Pakistan product catalog and cache-busts the CSS/JS/data files on every deployment.
